FITTRACK PRO v24 — FUTURE WORKOUTS TAB

Key change:
- Future Workouts is now a permanent bottom navigation tab:
  Home | Workout | Future | Progress | More

This makes future workouts easy to find at all times.

Also improved app updating:
- Service worker cache bumped to v24
- index.html now uses network-first loading when online
- old cache versions are deleted on activation
- App Update section includes a Refresh App Version button

For GitHub Pages:
1. Delete/replace the old repository files with everything in this ZIP.
2. Keep index.html, manifest.webmanifest, sw.js, and icons/ in the repository root.
3. Wait for GitHub Pages to redeploy.
4. Open the site once in Safari.
5. Close and reopen the Home Screen app.

If the old layout still appears:
- Open More -> App Update -> Refresh App Version.
